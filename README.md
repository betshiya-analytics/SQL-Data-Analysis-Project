# SQL Data Analysis Project

## 📊 Project Overview

This project demonstrates the use of **SQL for data analysis** using an employee dataset.

The project includes SQL queries to explore employee information, analyze salaries, compare departments, and evaluate employee performance.

## 🎯 Objectives

* Analyze employee data using SQL.
* Calculate employee and department-level metrics.
* Filter and sort data to find useful information.
* Analyze salary and performance data.
* Practice SQL concepts used in Data Analytics.

## 🛠️ Tools & Technologies

* SQL
* Relational Database Concepts
* Data Analysis
* Data Filtering
* Data Aggregation

## 📌 SQL Concepts Used

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* COUNT()
* AVG()
* MAX()
* MIN()
* Aggregate Functions

## 🔄 Project Workflow

1. Created an employee dataset.
2. Stored the dataset in CSV format.
3. Wrote SQL queries to analyze the data.
4. Filtered and grouped employee information.
5. Calculated salary and performance metrics.
6. Extracted useful insights from the dataset.

## 📈 Analysis Performed

The SQL queries analyze:

* Total number of employees
* Employees by department
* Average salary by department
* Highest and lowest salary
* Employees with higher salaries
* Employee performance scores
* Department-wise employee count
